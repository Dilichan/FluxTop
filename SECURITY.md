# Безопасность и приватность

FluxTop читает сведения о процессах локального компьютера. Сборщик не отправляет
метрики по сети; в прототипе нет телеметрии, автоматического повышения привилегий,
инъекций или функций завершения чужих процессов. При запуске через `fluxtop.cmd`
launcher обращается к настроенному Git remote для обновления и выполняет
полученные сборочные файлы, тесты и программу. Используйте доверенную upstream-ветку;
`-NoUpdate` отключает сетевую проверку. Сам EXE сетевых запросов не делает.

Имена процессов и будущая история использования могут раскрывать сведения
о пользователе. Не публикуйте исходные журналы без просмотра и очистки.
Полные EXE-пути для будущих сцен будут храниться локально.

Не помещайте секреты, токены и персональные данные в issue или PR.
Если репозиторий поддерживает GitHub Private Vulnerability Reporting,
используйте его для чувствительных сообщений. До настройки приватного канала
не размещайте публично чувствительные детали; обычные ошибки можно сообщать
в issue с обезличенным примером.

Первая версия — экспериментальный прототип; официальных стабильных релизов
и отдельного периода поддержки пока нет.
