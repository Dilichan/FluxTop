# Безопасность и приватность

FluxTop читает сведения о процессах локального компьютера. Сборщик не отправляет
метрики по сети; в прототипе нет телеметрии, обхода системных ограничений,
инъекций или функций завершения чужих процессов. При запуске через `fluxtop.cmd`
launcher обращается к настроенному Git remote для обновления и выполняет
полученные сборочные файлы, тесты и программу. Используйте доверенную upstream-ветку;
`-NoUpdate` отключает сетевую проверку checkout. Скачиваемый FluxTop.exe обращается
к GitHub Releases для обновлений: HTTPS, размер, SHA-256 из API и встроенный тег
проверяются до активации. Сам процесс мониторинга данные по сети не отправляет.
Контрольная сумма не заменяет подпись издателя; подписи пока нет.

По умолчанию launcher запрашивает административный запуск EXE через UAC.
Git и сборке повышение не требуется; запускайте launcher из обычной консоли.
`-StandardUser` отключает запрос UAC и оставляет унаследованные права.
Повышенный монитор пытается включить назначенную ему `SeDebugPrivilege` для
чтения метрик. Защищённые процессы могут оставаться недоступными.
UAC не отключается; отмена запроса завершает запуск. См. [ADR-0002](docs/decisions/0002-administrator-monitor.md).

Имена процессов и записываемая история использования могут раскрывать сведения
о пользователе. Не публикуйте исходные журналы без просмотра и очистки.
Полные EXE-пути и показатели уже хранятся локально в history.db.
Кеш `icons.db` уже хранит локальные EXE-пути и сжатые иконки, без сетевой отправки.
Извлечение выполняется из ресурсов EXE без запуска наблюдаемого приложения;
совпадение PID дополнительно проверяется по времени создания процесса.

Не помещайте секреты, токены и персональные данные в issue или PR.
Если репозиторий поддерживает GitHub Private Vulnerability Reporting,
используйте его для чувствительных сообщений. До настройки приватного канала
не размещайте публично чувствительные детали; обычные ошибки можно сообщать
в issue с обезличенным примером.

Первая версия — экспериментальный прототип; официальных стабильных релизов
и отдельного периода поддержки пока нет.
