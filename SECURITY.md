# Безопасность и приватность FluxTop

FluxTop собирает сведения о ресурсах локальных процессов. **Сборщик и оверлей не отправляют историю приложений, метрики, EXE-пути и содержимое SQLite на сервер.** Телеметрия и пользовательский аккаунт не требуются.

## Сеть и обновления

- **Установленный `FluxTop.exe`** обращается к GitHub Releases по HTTPS при открытии клиента. Проверка и скачивание — разные действия: файл загружается только после согласия пользователя. Обычный запуск и автозагрузка не устанавливают обновления автоматически.
- **`FluxTopSource.exe` для разработчиков** может выполнять Git fetch настроенной upstream-ветки до запуска монитора. Слияние — только fast-forward, при отсутствии локальных изменений; `--no-update` выключает сетевую проверку. Полученные исходники, CMake-файлы и тесты выполняются как код — используйте доверенный Git remote.
- Скачиваемый updater проверяет размер, HTTPS/TLS, SHA-256 из GitHub API, формат PE и версию EXE. Проверка целостности не заменяет подпись издателя. Публичный EXE пока не подписан сертификатом.

## Привилегии Windows

Основной запуск монитора запрашивает UAC через Win32. При отказе повышение не выполняется. Запуск без запроса прав через `--standard-user` допустим в исходном launcher-е для тестов, но часть метрик может быть недоступна. При наличии разрешения токена монитор может попытаться включить `SeDebugPrivilege`; обхода PPL/защищённых процессов, отключения UAC, инъекций и установки драйвера нет. Подробнее: [ADR-0002](docs/decisions/0002-administrator-monitor.md).

## Локальные данные

- `%LOCALAPPDATA%\FluxTop\fluxtop.db` хранит агрегированную историю приложений и кеш иконок; SQLite также использует `fluxtop.db-wal` и `fluxtop.db-shm`.
- `overlay.ini` содержит пользовательские настройки. `activity.log` и архивы — события работы приложения, пути и диагностические сведения; они могут быть чувствительными.
- Удаление программы через `Uninstall-FluxTop.exe` оставляет базу, настройки и журналы для повторной установки. Для полной очистки пользователь удаляет их вручную **после завершения FluxTop**.
- Не прикладывайте необработанные БД и логи к публичным issue. Проверьте их на личные имена, EXE-пути, историю приложений и прочие конфиденциальные сведения.

## Ответственное раскрытие

Если GitHub Private Vulnerability Reporting включён, используйте его для уязвимостей. Не публикуйте публично эксплуатационные детали и приватные данные. Обычные ошибки можно отправлять в [Issues](https://github.com/Dilichan/FluxTop/issues) с обезличенным примером.

Исходный код распространяется по [MIT](LICENSE). Заявление о размере RAM — целевой бюджет, а не гарантия безопасности или производительности.
