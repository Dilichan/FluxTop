# FluxTop: настройка ползунков и адаптивная анимация

Патч после коммита `b428eb8` (после релиза 0.2.4, пока без нового тега).

- Размер текста — дискретный Win32 Trackbar с шагом 1 и диапазоном 5–42 px.
- Интервал сбора — дискретный Trackbar с шагом 1 и диапазоном 1–10 секунд.
- Настройки по-прежнему сохраняются в `overlay.ini` под ключами `font_size` и `interval_ms`.
- Обновление значений при перетаскивании отложено; подпись обновляется сразу. После отпускания применяется новое значение.
- Анимация ищет прежние позиции через хеш-индекс PID с дополнительной проверкой времени создания процесса вместо вложенного поиска O(n²).
- Анимация не запускается, если изменились только строки вне видимой области.
- При анимации перерисовывается только изменившаяся вертикальная область; неподвижные строки не отправляются повторно в DirectWrite. Full-image `UpdateLayeredWindow` пока остаётся.
- Программный рендерер адаптивно пропускает кадры после дорогостоящего `UpdateLayeredWindow`, не задерживая основной UI-поток дополнительными синхронными действиями.
- Если хотя бы один кадр перемещения занял 45 мс или больше, в `activity.log` однократно за переход пишется `overlay.animation_slow render_ms=... rows=... visible=...`.

Отсутствие логов `animation_slow` не доказывает соблюдение целевого FPS. Для оценки нужен реальный замер с 100 строками, особенно при высоком разрешении и шрифте.

Без изменения логики сбора, источников CPU/GPU, структуры SQLite, сортировок, чисел интервалов и алгоритма AutoScore. Старые данные пользователя не удаляются.
