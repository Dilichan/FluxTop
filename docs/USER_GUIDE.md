# Руководство пользователя

## Установка и запуск

Скачайте FluxTop.exe из [официальных релизов](https://github.com/Dilichan/FluxTop/releases).
Выбирайте файл в Assets, а не Source code. Windows 10/11 x64; ARM64 и 32-битная
Windows не проверены. Git и инструменты разработки не нужны.

Двойной щелчок запускает установку FluxTop для текущего пользователя. После
подтверждения в меню «Пуск» появляется FluxTop, а в настройках Windows — запись
для удаления. Установка запрашивает UAC. Установленный launcher подготавливает
монитор и запрашивает UAC для сбора метрик. При отказе программа не запускается.
Проверка новых релизов выполняется при открытии клиента, без автоматической установки. EXE пока не подписан сертификатом
издателя, контрольная сумма SHA-256 опубликована рядом с ним.

## Клиент и оверлей

Вкладка **«Статистика»** показывает AutoScore в реальном времени (последняя минута),
историю за 24 часа, 7 дней или выбранный календарём период, а также наблюдаемый
аптайм приложений с иконками. По умолчанию системные приложения скрыты.
Подробнее: [STATISTICS.md](STATISTICS.md).

- Число приложений: 1–100, ползунок. Это только видимые строки.
- CPU/RAM/GPU/GPU RAM/Rx/Tx: сортировка по нужному показателю. Сортировка Rx/Tx
  использует сумму приёма и передачи. «Авто» учитывает постоянную нагрузку
  и всплески всех видимых ресурсов, включая сеть; первая строка закрепляется
  за приложением, окно которого находится в фокусе.
- Флажки показателей выбирают столбцы. Снятие всех флажков оставляет общие итоги.
- «Только общие показатели» оставляет одну строку без списка процессов.
- Шрифт: 5–42 px, выпадающий список. Непрозрачность: ползунок 1–100%.
- Сбор и обновление: 1–10 целых секунд, применяется без перезапуска.
- Числовые значения применяются после паузы ввода, ошибочные не сохраняются.
- Для перемещения включите «Перемещать оверлей мышью», перетащите оверлей,
  затем выключите настройку. В этом режиме колесо прокручивает длинный список.
- Обычный оверлей пропускает клики в приложения под ней.

В шапке справа от названия показаны системные итоги. В оверлее отдельные
процессы **объединяются в приложение** по полному EXE-пути, даже если имеют
несвязанные деревья родителей. При недоступном пути возможна только проверенная
группировка родственников. Независимые профили с одним EXE показываются
в одной строке. CPU, Working Set, GPU RAM и Rx/Tx суммируются, GPU% берётся как
максимум по группе. Сумма Working Set может повторно учитывать общие страницы:
это не точное уникальное использование физической памяти. История остаётся по PID.
Значения в оверлее могут не складываться в системный итог: разделяемые ресурсы
и системный учёт отличаются.
Rx/Tx означает «приём / передача», с общей единицей KiB/s или MiB/s.
`—` означает отсутствие достоверных данных, а не нулевую нагрузку.
«Время сбора» в клиенте — длительность одного опроса, не интервал обновления.
«Иконок в памяти» — ограниченный RAM-кеш, не число иконок в БД.
«Записей показателей в БД» — количество сохранённых строк истории процессов.

## Трей и автозапуск

Закройте или сверните клиент, чтобы оставить оверлей и трей. История продолжает
записываться даже при скрытом оверлее. Двойной клик по значку трея или
Ctrl+Alt+F9 открывает клиент. Ctrl+Alt+F10 переключает видимость оверлея.
Если сочетание занято другим приложением, используйте меню трея.
Для полного выхода выберите «Завершить работу» или «Выход» в трее.

Автозапуск включается только вашей галочкой в клиенте. После входа в Windows
он ждёт 30 секунд и запрашивает UAC без проверки обновлений. Оверлей запускается,
клиент остаётся закрытым. Настройка не отключает UAC и не сохраняет разрешение
на повышение. Перед удалением FluxTop выключите автозапуск.

## История и обновление

В `%LOCALAPPDATA%\FluxTop\fluxtop.db` хранится одна SQLite-база:
таблицы иконок и истории с агрегатами за минуты, часы и дни. Подробные
снимки всех процессов каждую секунду на диск не записываются. Для
истории действует аварийный предел 50 ГиБ, суточные агрегаты — до 10 лет.

При открытии клиента FluxTop проверяет новые GitHub Releases. Если версия новее,
клиент предлагает установить её: **отказ не запускает скачивание**. После согласия
пакет скачивается и проверяется по размеру, SHA-256 и встроенной версии;
работающий монитор корректно закрывается только после скачивания. Обновлённая
версия запускается автоматически. История и настройки сохраняются.
При обычном запуске приложения и автозапуске Windows обновления не проверяются.

В папке данных находятся `overlay.ini`, `fluxtop.db`, служебные файлы WAL/SHM,
`activity.log` с ротацией до 500 МиБ, `FluxTop.exe`, каталог versions/ и
при необходимости предыдущий launcher `FluxTop.previous.exe`.
Не удаляйте файлы БД/WAL/SHM у работающего приложения. Для резервной копии
сначала полностью завершите программу и скопируйте папку данных.
При ошибке истории клиент показывает текст ошибки, старые данные не удаляются.

## Ограничения Preview

Показатели зависят от прав, драйверов и доступности счётчиков Windows.
Некоторые защищённые процессы недоступны даже администратору. Сеть включает
LAN, loopback, TCP и UDP; VPN/прокси могут менять привязку трафика к процессам.
Бюджет 50 МиБ — цель для клиента в трее с активным оверлеем, а не подтверждённый
результат текущей версии. Эксклюзивный полноэкранный режим не гарантируется.
Температура CPU может оставаться `—°C`: Windows не гарантирует прямой датчик
CPU Package. FluxTop использует доступные HWiNFO/WMI и явно обозначенные CPU
thermal zone / CPU Socket материнской платы. `MB` означает показание платы,
а не температуру кристалла. Встроенного аппаратного драйвера пока нет.

Для сообщения об ошибке укажите версию, Windows и шаги воспроизведения в
[Issues](https://github.com/Dilichan/FluxTop/issues). Не прикладывайте целиком
личную fluxtop.db: она содержит имена приложений, пути и историю активности.

## Режим установщика

Скачанный FluxTop.exe предлагает установку для текущего пользователя и запрашивает UAC.
Установленный launcher находится в `%LOCALAPPDATA%\FluxTop\FluxTop.exe` и доступен
через меню «Пуск». Настройки и история располагаются рядом, в той же папке,
но **не удаляются** штатным удалением приложения. Путь установленного EXE
используется уже существующим механизмом обновления через GitHub Releases.

При повторном открытии скачанного EXE программа сообщает, что FluxTop установлен,
и предлагает запустить или обновить копию. Если оверлей уже работает, запуск
второго экземпляра не выполняется. При входе в Windows автозапуск не включается
автоматически: настройка управляется только клиентом.

В «Установленных приложениях» можно удалить программу. Предварительно нужно
закрыть её через трей. Удаляется launcher, кеш извлечённых версий, ярлык меню
«Пуск» и собственный Startup-ярлык. `fluxtop.db`, `overlay.ini`
остаются на диске. Для полной очистки пользователь может вручную удалить
оставшуюся папку `%LOCALAPPDATA%\FluxTop` после завершения приложения.

Диагностика без изменения настроек: `tools/Check-FluxTop-Installation.ps1`.
Тест реального входа пользователя и запроса UAC требует ручной проверки.
