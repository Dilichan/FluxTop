# История выпусков FluxTop

## FluxTop 0.2.1 — 18 ноября 2026

Первый стабильный выпуск нативного EXE для Windows 10/11 x64 после
`v0.2.0-preview.1`. Обновление из Preview проверяется отдельно после
публикации GitHub Release.

### Исправлено и добавлено

- GPU RAM игры и других процессов: резервный PDH-счётчик `GPU Process Memory`
  при недоступном/нулевом D3DKMT; проверки значений, LUID и жизненного цикла PID.
- Многопроцессные программы: в оверлее объединяются все процессы с одним
  нормализованным полным EXE-путём, включая независимые корни процессов.
  Chrome, Edge, Firefox, VS Code, Electron не требуют специальных правил.
  Без доступного пути используется лишь проверенное родство процессов.
- Агрегируются CPU, RAM Working Set, GPU RAM, Rx/Tx. Загрузка GPU% группы —
  максимум по процессам, а не сумма несопоставимых GPU-движков.
- В режиме «Авто» активное окно закрепляет приложение первой строкой;
  остальное остаётся в AutoScore-порядке. Обновление смены фокуса событийное.
- Рейтинг учитывает устойчивую нагрузку и краткие всплески по выбранным
  показателям. Индивидуальная цветовая индикация метрик; оранжевые всплески.
- CPU Package/Die: поддержка HWiNFO Shared Memory и LibreHardwareMonitor /
  OpenHardwareMonitor WMI, плюс резервные явно обозначенные датчики CPU на
  материнской плате / в ACPI. Значения платы отмечаются `MB`.
- В клиенте независимые переключатели окраски системных итогов и строк.
- История SQLite сохраняется по отдельным PID без изменения схемы группировкой.

### Известные ограничения

- CPU температура не гарантирована: в Windows отсутствует универсальный API
  CPU Package, а встроенного драйвера аппаратных датчиков у FluxTop пока нет.
  `—°C` означает, что пригодный источник недоступен.
- Суммарная RAM приложения — сумма Working Set, которая может включать
  общие физические страницы. Это не объём уникальных физических страниц.
- Разные независимые профили с одинаковым полным EXE-путём теперь
  объединяются в одну строку; пути, которые Windows не дала прочитать,
  могут остаться отдельными. Сравнение с Get-Process требует одинакового
  момента и набора доступных PID.
- GPU% в группе — максимум, а не глобальная загрузка всех GPU-движков;
  некоторые драйверы не отдают GPU-метрики. Лимит 50 МиБ пока не подтверждён.
- Эксклюзивный fullscreen, аппаратные датчики некоторых ноутбуков и
  корректный учёт систем с несколькими процессорными группами не гарантированы.

### Проверка перед публикацией

Локальные CMake/CTest и Windows CI должны завершиться успешно. Пропуск

## FluxTop 0.2.0 Preview

Первый готовый EXE для Windows 10/11 x64. Скачайте **FluxTop.exe** в Assets и запустите двойным щелчком. Git, компилятор и установка Visual C++ Runtime не нужны.

- Прозрачный оверлей: CPU, RAM, GPU, GPU RAM и объединённый Rx/Tx.
- Общая загрузка системы прямо в заголовках, без лишней строки.
- Настройки применяются автоматически: 1–100 процессов, шрифт, непрозрачность 1–100%, выбранные столбцы, режим только общих показателей и интервал 1–10 секунд.
- Сортировка по каждому ресурсу, приёму, передаче, суммарному трафику или всплескам нагрузки («Авто»).
- История всех процессов в локальной SQLite без автоматического удаления. Графики истории ещё не реализованы.
- Автозапуск в трей с запросом UAC.
- Проверка новых релизов встроена в EXE: размер, SHA-256, запуск новой версии отдельным процессом, сохранение предыдущего launcher-а при ошибке активации.

**Запуск:** подтвердите UAC, чтобы сборщик мог читать больше процессов и сетевой трафик. При отмене UAC программа не запускается. `Ctrl+Alt+F9` открывает клиент, `Ctrl+Alt+F10` показывает/скрывает таблицу. Закрытие клиента оставляет программу в трее; полный выход — кнопкой «Завершить работу».

Это предварительная версия: бюджета 50 МиБ пока не заявляем, некоторые показатели могут быть недоступны из-за защиты процессов или драйверов. Сеть включает LAN/loopback, это не счётчик провайдера. Установочной цифровой подписи пока нет; SHA-256 опубликован в SHA256SUMS.txt. Не отключайте защиту Windows ради запуска.

Данные хранятся в `%LOCALAPPDATA%\FluxTop`, не отправляются в сеть и переживают обновление. EXE обращается к GitHub только для проверки/скачивания релизов. Для обновления уже работающего монитора завершите FluxTop и откройте EXE снова.
