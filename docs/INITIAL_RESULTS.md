# Первичная проверка прототипа 0.1.0

Дата: 18 ноября 2026 года. Исходники — начальная локальная версия,
ещё без опубликованного commit. Сборка Release x64, MSVC 19.51.36260,
Windows SDK 10.0.26100.0, CMake + Ninja. Версия ядра Windows — 10.0.26200.0,
32 активных логических процессора.

## Функциональная проверка

- Сборка прошла с `/W4 /WX`.
- 4/4 проверки CTest: расчёты/формат/аргументы, help, ошибочный интервал, live smoke.
- JSONL дополнительно разобран `ConvertFrom-Json`: 2 записи, schema v1,
  режим GPU disabled, ненулевой собственный Working Set.
- В отдельном коротком запуске GPU backend вернул `ready`, значения
  загрузки были доступны примерно для 30 процессов.
- Локальные ссылки документации и исключение build/экспортов из Git проверены.

## Короткий замер

По 3 прогревочных + 15 измеряемых снимков на режим, интервал 1000 мс.
В обоих режимах включён JSONL, TOP 1; наблюдались все процессы.
Режимы выполнялись последовательно. Система имела другую активную нагрузку,
а во время части замера выполнялись дополнительные короткие проверки.
Это предварительная проверка работоспособности, не контролируемый benchmark.

| Показатель | GPU включён | GPU выключен |
| --- | ---: | ---: |
| CPU average, % всей системы | 0,0611 | 0,0612 |
| Working Set median / max, МиБ | 14,480 / 14,488 | 5,805 / 5,820 |
| Private Bytes median / max, МиБ | 8,793 / 8,793 | 1,145 / 1,156 |
| Время сбора median / max, мс | 24,713 / 36,599 | 24,060 / 32,595 |
| Handles начало / конец | 85 / 85 | 63 / 63 |
| Количество процессов min–max | 513–519 | 513–521 |
| Неполные CPU/RAM строки, max | 277 | 277 |
| Статус GPU | ready | disabled |

Замер выполнен в ограниченной среде с большой долей недоступных процессов;
он не доказывает покрытие всех приложений обычного пользовательского сеанса.
GPU idle внешним инструментом не измерялся. ETW, оверлея, SQLite и их затрат нет.
Короткий период и разрешение process CPU time ограничивают точность CPU.
Из этих чисел нельзя делать вывод о достижении общего бюджета ≤50 МиБ / ≤0,5% CPU.

## Воспроизведение

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Measure-FluxTop.ps1 -Executable .\build\ninja\fluxtop.exe -Samples 15 -WarmupSamples 3
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Measure-FluxTop.ps1 -Executable .\build\ninja\fluxtop.exe -Samples 15 -WarmupSamples 3 -NoGpu
```

`ExecutionPolicy Bypass` действует только на запущенный процесс PowerShell;
системные настройки не изменяются. Используется для локально написанного скрипта,
если действующая политика запрещает запуск `.ps1`.
Для полноценного сравнения см. [методику](PERFORMANCE.md): 30 секунд прогрева,
10 минут измерений, фиксированное оборудование и независимый замер CPU.

В текущей ограниченной среде MSBuild остановился в FileTracker с отказом доступа.
Локальная проверка выполнена через Ninja с тем же MSVC; путь Visual Studio
из README и GitHub Actions ещё требует отдельного запуска вне этой среды.
