# FluxTop — логотип и иконки

Векторная реконструкция PNG, предоставленного владельцем проекта.
Сохранены монитор, орбита, пульс, цветные столбцы и форма надписи FluxTop.
Растровый шум и ореол вокруг контуров удалены; фактуры исходного PNG заменены
чистыми градиентами. Это реконструкция изображения, не побитовая копия.

| Файл | Назначение |
| --- | --- |
| `fluxtop-logo.svg` | Полный логотип с надписью; прозрачный фон, viewBox 1254×1254 |
| `fluxtop-mark.svg` | Подробный знак без надписи; квадратный viewBox 1040×1040 |
| `fluxtop-mark-small.svg` | Упрощённый знак для 16–48 px; viewBox 32×32 |
| `fluxtop.ico` | Windows: 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 px, RGBA |

SVG содержат векторные фигуры, градиенты и контуры букв. Встроенных PNG,
внешних ссылок и зависимости от установленных шрифтов нет.
Полная надпись с тёмным `Flux` рассчитана прежде всего на светлый фон;
в маленьких иконках используется знак без текста.

## Использование

- SVG — мастер для масштабирования, README, сайтов и печати.
- ICO — встроенный ресурс `IDI_FLUXTOP` (101) в `fluxtop.exe`.
- EXE, оконный класс и трей используют один ресурс; размер выбирается под DPI.
- Кадры 16–48 px используют упрощённый знак, 64–256 px — подробный.
- Установка SVG-движка или внешних файлов изображений для запуска не требуется.

## Пересоздание ICO и PNG

Нужны Python 3 с Pillow и Inkscape CLI только на машине, где меняют графику.
Обычная CMake-сборка использует уже подготовленный ICO и этих инструментов не требует.

```powershell
python .\tools\export_brand_icons.py
# Если Inkscape не найден автоматически:
python .\tools\export_brand_icons.py --inkscape 'C:\Program Files\Inkscape\bin\inkscape.com'
```

Скрипт читает SVG, обновляет `fluxtop.ico`, проверяет каталог размеров ICO
и создаёт PNG плюс `branding-preview.png` в исключённой из Git папке
`out/branding/`. Исходный PNG для повторного экспорта не нужен.
После изменения ICO CMake пересобирает Windows-ресурс.

Windows может кешировать старую иконку EXE/ярлыка. Перезапуск приложения
применяет новый ресурс к трею и окну; существующий ярлык может потребовать
обновления самим Explorer. Системный кеш автоматически не очищается.
