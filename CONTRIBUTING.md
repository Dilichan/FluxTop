# Участие в разработке

FluxTop разрабатывается открыто. Изменения должны сохранять нативную
архитектуру и учитывать стоимость фоновой работы.

Перед изменением прочитайте [стек](docs/STACK.md) и [архитектуру](docs/ARCHITECTURE.md).
Для заметного изменения архитектуры сначала опишите причину, альтернативы
и ожидаемое влияние на CPU, память и совместимость в issue или PR.

## Код и проверки

- C++20, Unicode Win32 API, RAII для системных ресурсов.
- Избегайте неограниченных кешей, очередей, частого polling и постоянных UI-анимаций.
- Проверяйте расчёты CPU, смену идентичности процесса и отсутствующие данные тестами.
- Ошибки доступа не превращайте в нули или выдуманные показатели.
- PR должен включать описание поведения, способ проверки и ограничения.
- Для оптимизаций приложите сравнимые замеры Release до и после.
- Не добавляйте бинарники, логи, EXE-пути своей машины, базы истории и секреты.

## Сторонний код

Новый код проекта распространяется по MIT. При заимствовании сначала
проверьте совместимость лицензии, сохраните атрибуцию и добавьте notice.
Простая ссылка на другой репозиторий не даёт разрешения копировать его код.
Новые зависимости требуют зафиксированной версии и описания происхождения.

Сообщение об ошибке должно содержать версию/commit, Windows, оборудование,
настройки запуска и минимальные шаги воспроизведения. Перед публикацией
логов удалите персональные сведения и имена внутренних приложений.
